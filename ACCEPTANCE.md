# ACCEPTANCE — Portfolio React TS Vite

## Build et démarrage
- [ ] `npm install` fonctionne.
- [ ] `npm run dev` démarre l'application.
- [ ] `npm run build` termine sans erreur TypeScript/Vite.

## Navigation
- [ ] `/` fonctionne.
- [ ] `/about` fonctionne.
- [ ] `/projects` fonctionne.
- [ ] `/projects/:id` affiche le bon projet.
- [ ] `/contact` fonctionne.
- [ ] `/builder` fonctionne.
- [ ] Les liens internes ne provoquent pas de rechargement inutile.

## Accueil
- [ ] Nom et titre visibles.
- [ ] Présentation claire.
- [ ] CTA vers projets et CV.
- [ ] Technologies principales visibles.

## Profil
- [ ] Bio affichée depuis le JSON.
- [ ] Compétences affichées avec niveau.
- [ ] Expériences affichées chronologiquement.
- [ ] Certifications affichées.

## Projets
- [ ] Cartes projet complètes.
- [ ] Filtre par technologie.
- [ ] Tri par année.
- [ ] Détail accessible par id.
- [ ] GitHub/démo affichés seulement lorsqu'ils existent.
- [ ] État vide compréhensible.

## Contact
- [ ] Champs validés côté client.
- [ ] Messages d'erreur compréhensibles.
- [ ] État de succès visible.
- [ ] Aucun backend nécessaire au MVP.

## Builder
- [ ] Sélection d'un type de contenu.
- [ ] Questions affichées étape par étape.
- [ ] Réponses conservées lors de la navigation.
- [ ] Validation avant génération.
- [ ] Prévisualisation correcte.
- [ ] JSON généré conforme au type.
- [ ] Copie/téléchargement du JSON.
- [ ] Brouillon local possible avec `localStorage`.
- [ ] Aucune promesse de modification automatique du dépôt.

## Responsive
- [ ] Mobile.
- [ ] Tablette.
- [ ] Desktop.
- [ ] Navigation adaptée aux petits écrans.
- [ ] Aucun débordement horizontal.

## Accessibilité
- [ ] Navigation clavier.
- [ ] Focus visible.
- [ ] Labels de formulaire.
- [ ] Alt text pertinent.
- [ ] Contraste suffisant.
- [ ] Réduction des animations si `prefers-reduced-motion` est active.

## Thème et qualité
- [ ] Dark mode cohérent.
- [ ] Animations discrètes.
- [ ] Pas de données fictives présentées comme réelles.
- [ ] Pas de secrets dans le frontend.
- [ ] README à jour.
- [ ] Aucun warning critique au build.

## Acceptation finale
Le projet est accepté lorsque les fonctionnalités MVP sont utilisables, les critères ci-dessus sont vérifiés et `npm run build` passe avec succès.
